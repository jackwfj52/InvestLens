# G28：同快照 Bull/Bear 审查

Bull/Bear 各一次正常调用，使用冻结的同一 snapshotHash、假设、获准证据摘要和可计算指标；不重新取数、不多轮辩论。共享持久模型/修复/重试额度及进程内两个模型并发槽，等待并发槽也计入 Permit 时间。当前按步骤串行执行，单侧超时或结构错误保存 MISSING 检查点，继续另一侧及 Judge；模型关闭明确 DISABLED。

版本化 Prompt 固定 Claim 字段、引用范围、成立/失效条件和未知项。实际 G01 Schema 随 Maven 打包，ContractSchemas 执行本项目冻结契约使用的类型、引用、字段、组合条件、格式和范围关键词；不是开放式通用 Schema 服务。结构化响应最多尝试一次全局修复。非法引用、跨 Run/hash、错误角色、重复 Claim 被拒绝；不把用户冲击或规则通过当作宏观因果证据。

角色输出沿用原子 step_outputs 检查点和执行令牌；取消和迟到输出不能改变已有结果。用户已明确授权：在显式启用模型且由用户自行配置 URL 后，可发送通过许可筛选的冻结证据摘要、指标/情景和已有角色观点。本轮只用本机 stub 验证此路径，未在线发送真实组合。自由文本金融数值的发布前校验仍待 G31。
