# G31：金融数字发布闸门

结构校验后按指标名称校验比例、百分点、金额及归一化单位，采用 BigDecimal 从冻结后端指标生成展示值，不使用模型计算值。数字展示同时保留 metricId、原值、公式和证据引用。

自由文本采用保守拒绝策略：检查观点、条件、未知项、结论、说明和限制中的数字，覆盖 Unicode 数字、全角、中文金额/百分数及英文数词。即使数字看似与指标相同，也不能由模型直接写入；只能展示结构化指标。失败以 MODEL_OUTPUT_INVALID 阻断，不发布含违规文本的候选，不消耗额外修复调用。

发布仍需 G32 原子事务。模型连接默认关闭；本组只使用本机 stub，不向外部发送组合。
