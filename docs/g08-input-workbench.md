# G08 输入工作台与验收

工作台调用 G05/G06 的真实接口，支持新建、版本化修订、确认和按 ID 重新打开。浏览器仅记住上次两个 ID；原始想法、约束和组合持久化在 MySQL。禁用 localStorage 时仍可手动输入 ID。页面不调用模型，也不生成研究结果。

当前编辑范围为 USD、归一化 100 的合成组合：股票、黄金 ETF 代理、白银 ETF 代理和现金。零权重非现金行省略，现金行始终保留；代理报价单位是每份基金，不是金属现货。真实数据资格独立于输入功能。

百分比使用十进制字符串与 BigInt 精确转换，10% 写入 `targetWeight=0.1`；增加 10 个百分点写入 `deltaPercentagePoints=10`。组合权重精确合计 1，不使用浮点容差。期限可暂缺，保存成 NEEDS_INPUT；确认前必须补齐期限、假设、机制和检验方法。假设始终 UNVERIFIED。

保存组合不改变已有决策的引用；页面明确显示快照差异，保存决策才引用当前快照。载入最新组合不会改写历史快照。编辑后的决策保存为待确认，确认另生成不可变版本。PATCH 始终带读取时的 expectedVersion；409 展示保留输入、重新读取的提示，不自动覆盖或重试。后端字段错误与待补充字段可点击跳转；返回 traceId 可用于排查。

单个假设的最小表单暂不编辑多假设或未登记资产的决策，读取时明确拒绝，防止静默删减其他假设。组合名称只在创建时填写，已有快照不包含名称，不伪造读取结果。新建操作保留数据库中的旧输入，用户可用原 ID 重开。
