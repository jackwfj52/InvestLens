# G33：报告工作台与历史侧栏

工作台接入只读决策/Run 历史、原报告、后端数值展示和 Evidence Board。报告展示固定版本、模式/质量、生成方式、角色可用性、范围、假设评价、条件/未知项、阈值、缺口及冻结版本。指标展示使用已发布 figures，不采用模型数字。证据/指标引用使用 Run 隔离的页面锚点，来源链接只允许 HTTP(S)。

历史切换不会 POST 或改写编辑中的输入，旧请求在切换时中止且序号隔离，加载错误不残留上一份报告。创建研究绑定当前输入已计算的显式情景，情景变化生成不同幂等请求；模型未配置时可获得带缺口的确定性 PARTIAL 报告。已失败或取消且无报告单独展示。

进度的持续刷新及页面刷新恢复分别由 G34/G35 接入；本组先保留手动“读取任务状态”。前端单测覆盖版本/引用隔离和情景幂等键，执行类型检查与生产构建。
