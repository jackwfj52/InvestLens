# G15 指标、来源与情景工作台

技术实现已交付，**真实行情 M2 验收仍待数据源正式资格**。当前生产候选的大陆原生网络、使用条件和复权/公司行动未确认，页面会显示来源待确认并禁用历史计算，不以合成价格宣称真实历史闭环。

## 页面能力

- 固定输入区展示已保存组合的模式、版本、UTC 时间、snapshotId 与内容哈希。编辑未保存、决策未确认或快照不匹配时不能发起情景计算。
- 历史区连接 G13 的快照创建、指标计算与查询接口，按资产分组显示区间收益、样本年化波动率和最大回撤。只有服务端资格通过的组合资产允许取数；无数据、加载、样本不足和请求失败分别展示。指标保留公式版本、年化因子、实际样本窗/样本数和证据引用。
- 来源摘要展示 Provider、质量、数据模式、存储策略、原数据时间、抓取时间和证据 ID；来源链接只接受 http(s)。缺失值显示“不可计算”，不回落为零。
- 情景区从已确认的 DecisionVersion 与原 PortfolioSnapshot 创建独立组合输入，调用 G14 计算；展示前后权重、逐资产/总损益、集中度和原用户阈值结果。每个持仓（含现金与零权重资产）必须显式给冲击。
- SYNTHETIC 组合可手动填入已标记的 20/10/70 算术样例，不生成合成历史价格。金融数值来自后端，前端仅使用 BigInt 完成百分比输入换算及 HALF_UP 展示舍入。
- 首次计算后，修改冲击立即清除旧数字、取消旧等待，300ms 防抖重算；序号隔离保证旧请求即使忽略 AbortSignal 也不能覆盖当前参数。显式计算会清除待执行防抖，避免重复提交。
- 刷新后保留结果 ID，可通过普通 GET 重新打开原 Bundle/Scenario。历史显示使用原模式、版本、哈希和时间，和当前输入不同时明确提示；读取不创建新计算或 Run。新读取开始时清空上一份结果，失败时不会残留旧数字。

本组没有公开 Run API、后台研究或模型调用。输入页面保持合成 USD/归一化编辑边界；实际行情资格仍由后端控制。
