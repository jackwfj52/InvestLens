# G26：白名单研究工具

ToolRegistry 再次严格校验固定 Run/决策、资产白名单、有限日线窗口及无环依赖；仅执行已注册的四种工具，不接受 URL 或模型自定义参数。行情需求按资产单窗口去重，与模型步骤数无关，外部调用使用统一持久预算及动态超时。

行情先在事务外取数，再在持有有效执行令牌的事务中保存证据及计算结果。EvidenceService.freezeCollected 直接消费已取得的质量结果，不会二次请求 Provider。research_tool_results 保存同一 Run 的计划 hash 和工具结果；重领时复用已有结果，计划不匹配拒绝执行，取消或租约失效不允许落账。

REPLAY/SYNTHETIC 不请求实时源。用户显式指定的既有情景复用固定计算输入；没有显式冲击时记录 SCENARIO_INPUT_MISSING，不默认填零。数据、许可、样本问题保留结构化缺口，不伪装工具成功。G27 将接入创建时的情景引用和冻结 Manifest。
