# G27：完整研究快照与固定输入

创建 Run 可选传入 scenarioId，必须属于当前主体、相同已确认决策版本和组合快照；在创建事务中固定，并加入幂等请求 hash。省略时保留原五字段协议，不推断冲击值，不自动选择最新情景。

显式情景路径在模型关闭时也可运行确定性 Plan/Research/Quant。已存情景固定计算输入，不刷新行情；模型启用时仍只执行后端白名单。QUANT 后冻结一次 ResearchSnapshot，保存完整 Manifest、计划 hash、证据 payload hash、指标内容/公式/输入 hash、配置和 Prompt 版本，并绑定 Run。

证据与指标分配 Run 专属 ID，既有独立计算结果保持不可变；保留来源原时间、模式及许可。没有保存许可的内容不复制，角色输入只允许已保留、可供模型使用的有效证据。快照 hash 按 G01 排除 snapshotId、frozenAt、snapshotHash 后计算，不形成指标/快照循环。组合输入身份元数据与行情交易日历/口径分别冻结；没有行情时不冒充获准交易所元数据。

没有冲击情景时可以保留调仓指标和诊断，但不满足最低报告条件。G28 后续角色共用该冻结输入。当前只保存研究检查点，不发布正式报告。
