## 运行与安全边界

- 研究支持独立判断，不执行买卖或资金转移，也不保证预测/收益。宏观因果保持 UNVERIFIED，当前 Judge 只接受 INSUFFICIENT_EVIDENCE。
- P0 是本地单用户工作空间，不是可直接面向公网的多租户 SaaS；不要扩大回环端口绑定或移除安全策略。账户/并发限额不替代生产压测。
- `.env`、API Key、数据卷、原始输入、报告/回执/截图均不进 Git。有限敏感值审计不是全历史泄密审计、法律许可确认或渗透测试。
- Docker 启动不需宿主 Java/Node/Python，首次源码构建仍需要镜像/Maven/npm/PyPI 网络或已准备的离线包；没有网络缓存不保证冷构建成功。
- 当前纽约日历/资产/报价币种及公式口径是明确的首版约束；未提供跨币种、税费/滑点/融资、任意年份日历或全市场覆盖。
- 不使用 `down -v` 清空用户数据。换机器需安全迁移原命名卷或按许可重新生成；现有报告 JSON 不是数据库备份。
- 故障恢复覆盖详见验收矩阵；QUANT 后令牌恢复经过受控时钟测试，但真实在线长调用中杀进程及所有网络故障组合没有穷尽演练。
